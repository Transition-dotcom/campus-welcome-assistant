## 1. 快速开始

### 1.1 打开网站

在浏览器访问 **http://localhost:5173**（需要校内项目组先把服务启动好，启动方式见《部署说明》）。

### 1.2 注册账号

系统**没有预置的学生账号**，第一次使用请先注册：

1. 点击右上角「登录」，在登录页点「立即注册」；
2. 填写**昵称**（2-50 个字符，这就是你登录用的账号，起个自己喜欢的名字吧）；
3. **学号**可选填，先不填也没关系，之后可以在个人中心补充信息；
4. 设置**密码**（至少 6 位），再输一遍确认；
5. 点「注册」——注册成功后会自动登录，直接进入首页。

### 1.3 登录

用注册时的昵称 + 密码登录即可。登录状态会记住一段时间（access_token 2 小时，过期会自动用 refresh_token 静默续期，最长 7 天无需重新登录）。

> 小提示：`admin / admin123` 是管理员账号，专门用于后台管理，普通同学正常注册自己的账号就好。

## 2. 首页仪表盘

打开网站第一眼就是首页，一眼看全校园大小事：

- **热门课程评价**：点赞最多的 3 条老生经验，点击可跳到对应课程；

- **安全防线**：置顶的安全提醒，点卡片查看全部。

## 3. 选课评价

> 选课一时爽，期末火葬场——先看看学长学姐怎么说！

### 3.1 浏览课程

顶部导航「选课评价」进入课程列表，可以按**学院**（软件学院/理学院/外国语学院/马克思主义学院）和**类别**（通识必修/通识选修/专业必修/专业选修）筛选，点「筛选」生效。每门课都显示学分和评价数。

### 3.2 查看评价

点进课程详情，就能看到老生们留下的经验。评价包含：难度评分（1-5 星）、给分评分（1-5 星）、正文，以及点赞数。可以按「最新」或「最热（点赞多）」排序。

### 3.3 写评价

登录后在课程详情页的评价框里：

1. 拖动两个评分条（难度、给分）；
2. 写下你的真实体验（10-5000 字，说说老师风格、考试重点、避坑提示都行）；
3. 不想暴露身份？勾选「**匿名发表**」——匿名评价不会显示你的昵称；
4. 点「发表」，你的经验就能帮到下一届学弟学妹啦。

### 3.4 点赞 / 评论 / 收藏 / 举报

每条评价下方都可以：

- **点赞**：觉得有用点个赞，再点一次取消（评价的热度就是靠大家点赞攒出来的）；
- **评论**：点「评论」展开评论区，支持楼中楼回复（两级），友好讨论选课心得；
- **收藏**：点「收藏」存起来，之后在「我的收藏」（右上角头像菜单）随时翻看；
- **举报**：遇到广告、不友善内容点「举报」，填写原因（至少 5 个字），管理员会处理。

## 4. GPA 计算器

顶部导航「GPA 计算器」，帮你算算这学期能拿多少绩点。

1. 点「添加课程」新增一行，填写课程名、学分和成绩；
2. 右上角切换**百分制 / 五级制**：
   - 百分制：直接填分数；
   - 五级制：选优秀/良好/中等/及格/不及格；
3. 成绩一填好，下方实时显示 **GPA（总平均学分绩点）**。

计算规则（**东北大学官方算法**）：

- 单科绩点 = (百分制成绩 − 50) ÷ 10，60 分以下绩点为 0；
- 五级制换算：优秀 = 95（4.5）、良好 = 85（3.5）、中等 = 75（2.5）、及格 = 65（1.5）、不及格 = 0；
- GPA = Σ(课程学分 × 单科绩点) ÷ Σ(课程学分)；
- 只有「学分 > 0 且成绩已填写」的行才参与计算。

> 你填的课程**自动保存在本地浏览器**（localStorage），关掉页面再打开也不会丢。注意：换浏览器或清除浏览器数据会清空记录哦。

## 5. 社团导航

> 大学四年，总要加个组织、认识一群有意思的人。

「社团导航」页把浑南校区和软件学院的社团、学生组织都整理好了：

- **分类 Tab**：全部 / 学生组织 / 学术科技 / 志愿公益 / 文体艺术 / 创新创业 / 其他，一键切换；
- **搜索**：按名称搜索，快速定位（比如搜「NEX」）；
- **详情页**：社团简介、活动频率、招新要求、**防坑指南**（学长学姐的真心话）和联系方式；
- **招新日历**：详情页下方是该社团近期活动时间线（宣讲会、面试、开放日），首页也会展示全校最近 3 场活动。

对哪个感兴趣？记住联系方式，按招新日历的时间去参加就好。

## 6. 校园导览

> 第一天到浑南校区，别怕迷路——「校园导览」带你认路。

- **分类 Tab**：教学楼 / 食堂 / 宿舍 / 快递点 / 运动场馆 / 行政楼 / 其他；
- **地标详情**：每栋楼都有图文介绍、**开放时间**、**楼层指引**和**注意事项**（比如图书馆几点开门、食堂哪层好吃、浴池哪天休息）；
- **路径指引**：页面提供「宿舍 → 一号楼」「食堂 → 图书馆」等热门路线，标明步行方向和预估分钟数，跟着走就行；
- **信息纠错**：发现地标信息过时或写错了？点详情页的「📝 信息纠错」，写下正确信息提交，管理员审核后会更新。**校园信息靠大家共同维护！**

## 7. 办事攻略

报到、借书、选课、看病……第一次办这些事总有点懵？「校园攻略」按流程拆成了分步指引：

- 分类：全部 / 办事流程 / 生活指南 / 学习攻略；
- 点进攻略后是**竖排步骤条**，从上到下跟着做即可；
- 有的步骤还标了**关联地点**，方便你随时跳到校园导览查看位置。

从「新生报到注册流程」到「校医院就诊&医保报销」，报到前花 5 分钟过一遍，现场不慌张。

## 8. 新生任务

右上角头像菜单点「我的任务」（或首页任务进度卡），12 项新生成长任务等你打卡：

1. 每完成一项（参观图书馆、加入学生组织、完成体测……），点任务右侧的「**打卡**」按钮；
2. 顶部**进度条**实时更新你的完成情况；
3. 打卡越多，**勋章**越闪亮：

| 完成数量 | 勋章 |
|---------|------|
| 完成 ≥ 3 项 | 🥉 铜牌 |
| 完成 ≥ 5 项 | 🥈 银牌 |
| 完成 ≥ 10 项 | 🥇 金牌 |
| 12 项全部完成 | 💎 钻石 |

勋章等级在每次打卡后自动更新。冲个钻石勋章，给大学生活开个好头！

## 9. 安全防线

「安全防线」页面（首页安全卡片或菜单进入）整理了新生最需要的安全提醒：

- **置顶内容**：防诈骗提醒、宿舍安全守则、紧急电话（校园 110：024-83680110、校医院急诊：024-83689120），建议把这些号码存进手机通讯录；

出门在外，安全第一。遇到可疑情况，先冷静、再核实，拿不准就问辅导员。

## 11. 个人中心

登录后点击右上角头像（手机端在底部导航「我的」），可以：

- **个人信息**：查看资料，点「编辑」修改昵称、学院、专业、年级（如 2024）和头像 URL，点「保存」生效；
- **我的任务**：进入新生任务清单；
- **我的收藏**：查看收藏过的课程评价，再次点击可取消收藏；
- **退出登录**：在头像菜单底部。

如果账号是管理员（ADMIN），菜单里还会多一个「**管理后台**」，用于管理课程、社团、地标、纠错审核、举报审核、攻略、任务和用户。普通同学看不到也进不去，放心。

## 12. 常见问题 FAQ

**Q1：忘记密码怎么办？**
当前版本暂未提供自助找回密码功能。请把昵称告诉管理员，由管理员协助处理（管理员可在后台禁用异常账号；密码重置需管理员在数据库中操作）。所以注册后请务必记住自己的密码。

**Q2：为什么提示「请求过于频繁」（429）？**
登录和注册接口做了限流保护：同一 IP 每分钟最多 10 次。连续输错密码或反复刷新登录页可能触发。等 1 分钟再试即可，正常使用不会遇到。

**Q3：勋章怎么获得？怎么升级？**
登录后在「我的任务」打卡即可：完成 3 项拿铜牌、5 项银牌、10 项金牌、12 项全完成拿钻石。每次打卡后自动结算，不用手动领取。

**Q4：匿名评价会暴露我是谁吗？**
不会。匿名评价连管理员后台也不显示发布者昵称（只在数据库中留存用于追溯违规行为）。

**Q5：GPA 计算器里的数据会同步到服务器吗？**
不会。课程数据只保存在你自己的浏览器本地，别人看不到；但换设备或清除浏览器数据后会丢失。

**Q6：为什么有时候要重新登录？**
出于安全考虑，登录状态最长维持 7 天（refresh_token 有效期）。超过后需要重新登录；如果管理员在后台禁用了账号，也会立即被要求重新登录。

**Q7：手机能用吗？**
可以。页面做了响应式适配，窄屏下顶部导航会变成底部导航栏（首页 + 登录/我的），操作方式与电脑一致。

**Q8：发现地标信息有误、评价有不当内容，怎么反馈？**
地标：详情页「信息纠错」提交；评价：点「举报」填写原因。管理员后台会统一审核处理，感谢你帮忙维护校园信息！

**Q9：我只想随便逛逛，需要注册吗？**
大部分内容（课程评价、社团、地标、攻略、安全提醒、GPA 计算）不登录也能看。只有发评价、点赞、收藏、评论、举报、打卡和个人中心需要登录。
